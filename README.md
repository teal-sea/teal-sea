# Thomas Lince

Medellín, Colombia. I build AI agents that run a real business, and I run the business they run.

The main one answers a limo booking service's phone line in production today and carries the sale end to end: discovery, a quote off live rate logic, the close, the deposit. The voice is a vendor; the pricing, the availability and the booking write stay on my endpoints.

Small tools extracted from that work:

- [grounded-check](https://github.com/teal-sea/grounded-check): audits what a voice agent said against what its tools actually returned. Born from a quality monitor that flagged around 35 correct quotes as fabricated.
- [too-soon](https://github.com/teal-sea/too-soon): refuses to call an A/B test winner on a sample too small to carry one.

Also: [modalruns.com](https://modalruns.com), a browser guitar practice app. Built, launched, monetized.
